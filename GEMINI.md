# Stoneridge DSP — Real-Time Windows Audio Engineering Rules

## Hard Real-Time Audio Thread Invariants
- **Zero heap allocations, zero locks, zero logging, zero blocking COM calls** inside any audio callback (`WdmKsStream::AudioThreadMain`, `WasapiExclusiveStream::AudioThreadMain`, `InputProcessor::Process*`).
- **Hardware denormal protection (`FTZ`/`DAZ`)**, **MMCSS `"Pro Audio"` (`AVRT_PRIORITY_CRITICAL`)**, **`timeBeginPeriod(1)`**, and **EcoQoS power-throttling bypass** must be active on every real-time audio thread.
- **Never burst-call `bufferSwitch()`**: Maintain strict 1:1 hardware-to-ASIO callback cadence. Never run a `while` loop that invokes multiple DAW callbacks inside a single hardware period.
- **Never hold `IAudioRenderClient::GetBuffer()` across `bufferSwitch()`**: Render DAW audio first, then acquire `GetBuffer()` solely for the `< 10 µs` PCM conversion + `ReleaseBuffer()`.
- **USB Capture Burst Safety**: USB Audio capture endpoints deliver bursts up to ~10 ms even at 64-sample render IRPs. Keep at least 12–14 ms of capture IRPs in flight and never set ring-buffer drift-trim thresholds below 20–25 ms, or trims will induce cyclic underruns.
- **Format Conversion Scaling**: Match `ConvertFloatToPcm` and `ConvertPcmToFloat` scale factors (`32768.0f` / `8388608.0f` with saturation clamping) so 16-bit SQNR stays `> 92 dB` and 24-bit SQNR stays `> 138 dB`, with `NaN`/`Inf` sanitized.

## Stoneridge VST / WebView2 UI & Full-Toolchain Rules (`stoneridge-dom`, `stoneridge-vibreit`, & Future Plugins)
- **Full-Toolchain Audit Before Planning**: Always check installed skills (`literature-search-arxiv`, `literature-search-openalex`, `gemini-api-cli`, `generative_ui`, `chrome-devtools`), Marketplace plugins, and native validators (`pluginval`, `clap-validator`, `wpr.exe`, `browser` subagent) before finalizing any engineering or QA plan.
- **DSP, ABI Freeze & Multi-Engine Calibration**: Never reorder published parameter indices (`stoneridge-dom` `0..203`, `stoneridge-vibreit` `0..63`). Keep `processCore` zero-allocation (offload heavy IR/ER table rebuilds to an atomic double-buffer background worker), sleep inactive engines (`0% CPU`) after a 50 ms equal-power cosine crossfade, keep 4x True-Peak safety limiting active, and verify every factory preset via an offline RMS/Peak/DC audit (`RMS spread <= 6.5 dB`, `Max Peak <= -0.30 dBFS`).
- **Strict 7-Bit ASCII in WebView2 UI & `/utf-8` MSVC Flag**: Never embed raw multi-byte UTF-8 punctuation (`•`, `×`, `∞`, `—`, `–`, `·`, `°`, `Δ`) or UTF-8 BOMs in `ui/*.js`, `ui/*.html`, `ui/*.css`, or `src/*.h` string literals (Windows WebView2 decodes them as mojibake `â€¢`, `Ã—`, `-âˆž`). Use ASCII equivalents (`|`, `x`, `-INF`, `-`), verify `non_ascii_bytes == 0` across all `ui/*` and `src/*` files, and always pass `/utf-8` in `CMakeLists.txt` MSVC compile options.
- **Custom Stoneridge Popovers & Sleek 6px Scrollbars (No Native Win32 Controls)**: Never allow native Windows `<select>` popups or blocky Win32 scrollbars in the VST UI. Intercept `<select>` clicks with the custom Stoneridge dark-glass popover menu (`.sr-custom-select-menu`), style all scrollable lists with 6px pill `::-webkit-scrollbar` rules (`::-webkit-scrollbar-button { display: none }`), and style range sliders with `-webkit-appearance: none`.
- **Responsive Shaper Bottom Layout & CSS `@media` Hygiene**: Never nest base component styles (such as `.insp-preset-strip` or `.neuro-lab-bar`) inside `@media` queries at the bottom of `style.css`. Keep shaper bottom button strips (`.insp-modes-row`, `.insp-knobs-row`, `.seg-pill-btn`, `.neuro-lab-bar`) on non-overlapping responsive rows (`flex-wrap: nowrap; min-width: 0; white-space: nowrap; overflow: hidden; text-overflow: ellipsis`) verified at `960x620`, `1180x740`, and `1920x1200`.
- **Unmistakable `ECO` Mode, Click-to-Deselect Presets, & No Auto Match**:
  - Pressing `ECO` must visibly light an emerald `.eco-dot` LED, change the button text to `ECO: ON`, show an `ECO SAVER ON` OLED badge + floating toast notification, hide `.cloud-sea`/mist layers (`opacity: 0`), and throttle OLED repaints.
  - Clicking an already-active preset in the preset browser (or module sub-preset selector) a second time—or clicking the `x` clear button—must deselect it (`currentPresetIdx = -1`) and revert to `INIT | Default Patch` while honoring locked/pinned modules (`kLockMask`).
  - Never include Auto Match / Acoustic Match tabs or quick-match pills.
- **0% Idle WebView2 UI CPU & Zero Dead Controls**: Never leave continuous `requestAnimationFrame` loops, `backdrop-filter: blur()`, continuous CSS `text-shadow`/viewport animations, Canvas2D `shadowBlur`, or high-rate FFT JS `eval()` telemetry running. Use dirty-flag/event-driven rendering (`markDialDirty`, offscreen sprite caching) and verify every control + startup knob render via `browser` E2E before shipping.
- **MSVC Build Safety, VST3 Deployment & GitHub Suite Grouping**: Always build MSVC with `--parallel 2` (to avoid `C1060` heap exhaustion), install VST3 builds into both `C:\Program Files\Common Files\VST3` and `%LOCALAPPDATA%\Programs\Common\VST3`, and tag all Stoneridge GitHub repositories (`lenymadeit-ops/stoneridge-*`) with the `stoneridge-plugins` and `stoneridge-audio` topics.
